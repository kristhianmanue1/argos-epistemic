# Código de conducta

## Nuestro compromiso

Participantes y mantenedores deben colaborar sin acoso ni discriminación. Se
esperan críticas técnicas específicas, respeto por las personas y disposición
a corregir errores.

## Conducta esperada

- discutir evidencia, decisiones y efectos, no atributos personales;
- declarar incertidumbre y conflictos de interés;
- respetar privacidad, propiedad intelectual y divulgación coordinada;
- no publicar secretos, datos personales ni contenido privado;
- aceptar decisiones de moderación y mantener las conversaciones enfocadas.

No se toleran amenazas, acoso, insultos, contenido sexual no solicitado,
discriminación, doxxing ni represalias.

## Aplicación

Reporta incidentes de forma privada al mantenedor mediante las opciones de
reporte de GitHub. El mantenedor puede editar o eliminar contenido, cerrar o
bloquear conversaciones y restringir participación. Las decisiones deben ser
proporcionales, confidenciales cuando corresponda y documentadas para evitar
aplicación arbitraria.

Este código aplica a espacios del proyecto y a representación pública del
proyecto.
