# Soporte y reportes

Argos es una implementación de referencia en desarrollo temprano.

- Para bugs reproducibles, usa el
  [formulario de bug](https://github.com/kristhianmanue1/argos-epistemic/issues/new?template=bug.yml).
- Para propuestas de producto o contrato, usa el
  [formulario de mejora](https://github.com/kristhianmanue1/argos-epistemic/issues/new?template=feature.yml).
- Para dudas de instalación, API o interpretación de reportes, usa el
  [formulario de pregunta](https://github.com/kristhianmanue1/argos-epistemic/issues/new?template=question.yml).
- Para vulnerabilidades, usa el canal privado indicado en
  [SECURITY.md](SECURITY.md), nunca un issue público.

Antes de reportar, consulta los
[issues abiertos](https://github.com/kristhianmanue1/argos-epistemic/issues) y
prueba la release candidate más reciente cuando sea razonable. Incluye una
reproducción mínima, versión o commit, Python, sistema operativo y método de
instalación. Sanea reportes, rutas y fixtures: una huella o procedencia no
autoriza a publicar contenido del target.

No existe actualmente SLA, soporte comercial, compatibilidad `1.x` ni garantía
de respuesta. No publiques secretos, código privado ni datos personales.
