# Soporte

Argos es una implementación de referencia en desarrollo temprano.

- Para bugs reproducibles, usa el formulario de bug.
- Para propuestas de producto o contrato, usa el formulario de mejora.
- Para preguntas, abre una discusión si está habilitada; de lo contrario, un
  issue claramente marcado como pregunta.
- Para vulnerabilidades, sigue [SECURITY.md](SECURITY.md).

No existe actualmente SLA, soporte comercial, compatibilidad `1.x` ni garantía
de respuesta. No publiques secretos, código privado ni datos personales.
